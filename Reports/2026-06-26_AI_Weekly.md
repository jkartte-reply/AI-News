# AI Weekly Report — 26. Juni 2026

> Recherchiert am 26.06.2026 | Zeitraum: 19.06.–26.06.2026

## Executive Summary

Die Woche vom 19.–26. Juni 2026 stand im Zeichen regulatorischer Weichenstellungen und infrastruktureller Reife: Googles Gemini 3.5 Flash erreichte die allgemeine Verfügbarkeit mit nativer Computer-Use-Fähigkeit, Microsoft öffnete sein Work IQ-API-Layer für Entwickler, und der EU Digital Omnibus schob zentrale KI-Act-Pflichten um 16 Monate hinaus.

## Frameworks & Developer Tools

Microsoft vereint AutoGen und Semantic Kernel zum Microsoft Agent Framework (GA bei Build 2026) und gibt mit Work IQ die programmierbare Unternehmens-Wissensschicht für Agents frei; Cursor übernimmt Continue und verdichtet den AI-Developer-Tools-Markt weiter.

### Microsoft Agent Framework
**Release:** GA<br>**Datum:** 02.06.2026<br>**Relevanz:** 🔴

Microsoft hat AutoGen und Semantic Kernel zu einem einzigen, kommerziell unterstützten SDK für Multi-Agent-Systeme zusammengeführt. Das Framework ist wire-kompatibel mit dem Copilot Studio Agent-to-Agent-Protokoll (ebenfalls GA), sodass gemischte Deployments ohne Custom-Adapter möglich sind. Für Microsoft-Partner ist dies die erste produktionsreife SDK-Basis für Unternehmensagenten auf der Azure-Plattform — geeignet für LangGraph-, Copilot-Studio- und reine SDK-Architekturen.

[Microsoft Foundry Blog](https://devblogs.microsoft.com/foundry/agent-service-build2026/) · [DEV Community Build 2026](https://dev.to/akaranjkar08/microsoft-build-2026-developer-preview-windows-agent-runtime-multi-model-copilot-and-the-agentic-5pi)

### Work IQ APIs
**Release:** GA<br>**Datum:** 16.06.2026<br>**Relevanz:** 🔴

Work IQ ist die Workplace-Intelligence-Schicht für Agents und erfasst, wie Arbeit tatsächlich in Microsoft 365, organisatorischen Systemen und externen Quellen stattfindet. Die APIs gingen am 16. Juni in GA und bieten Entwicklern programmatischen Zugriff auf Unternehmenskontexte wie Meetings, Dokumente und Workflows — die Basis für kontextsensitive Enterprise-Agenten ohne eigene Datenpipelines.

[Microsoft Foundry Blog](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-build-2026/) · [InfoQ](https://www.infoq.com/news/2026/06/microsoft-foundry-agents/)

Die Konsolidierung im AI-Coding-Tools-Markt beschleunigt sich.

## Neue Open-Source Libraries

Sicherheitsforscher deckten mit Agentjacking eine kritische Angriffsfläche für AI Coding Agents auf, die sofortigen Handlungsbedarf für alle Teams mit Claude Code, Cursor oder Codex auslöst; vLLM und Ollama bleiben die dominanten Open-Source-Inference-Engines für produktive und lokale Deployments.

### Agentjacking PoC (Tenet Security)
**Typ:** Security Research<br>**Stars:** —<br>**Datum:** 12.06.2026<br>**Relevanz:** 🔴

Tenet Security veröffentlichte einen Proof-of-Concept für Agentjacking: Angreifer injizieren über manipulierte Sentry-Fehlerberichte Schadcode in AI Coding Agents (Claude Code, Cursor, Codex). Der Angriff erfordert lediglich einen öffentlich zugänglichen Sentry DSN-Key und erzielt eine Erfolgsquote von ~85%. Das Forscherteam bestätigte über 100 reale Fälle bei Fortune-500-Unternehmen. Entwicklerteams sollten umgehend Sentry-DSN-Rotation, Agent-Sandbox-Isolation und Prompt-Injection-Abwehr implementieren.

[The Hacker News](https://thehackernews.com/2026/06/agentjacking-attack-tricks-ai-coding.html) · [Cloud Security Alliance](https://labs.cloudsecurityalliance.org/research/csa-research-note-agentjacking-mcp-sentry-injection-20260612/)

### vLLM
**Typ:** Python / Inference<br>**Stars:** 172K+<br>**Datum:** 03.04.2026<br>**Relevanz:** 🟡

vLLM v0.19.0 bleibt der Industriestandard für hochdurchsatzfähige GPU-Inferenz und erreicht laut Community-Benchmarks bis zu 19× den Durchsatz von Ollama bei parallelen Anfragen. Das Projekt treibt Produktionfeatures bei Amazon und LinkedIn an. Für Teams, die Modelle selbst hosten, ist vLLM der erste Evaluierungskandidat für Server-seitige Inferenz.

[GitHub vllm](https://github.com/vllm-project/vllm) · [Tech Insider Benchmark](https://tech-insider.org/vllm-vs-ollama-2026-2/)

### Ollama
**Typ:** Go / Local Inference<br>**Stars:** 172K<br>**Datum:** 03.05.2026<br>**Relevanz:** 🟢

Ollama v0.6.8 kombiniert Modell-Management, Deployment und eine OpenAI-kompatible API in einem einzigen Tool und ist besonders für Apple-Silicon optimiert. Mit 172.000 GitHub-Stars ist es das meistgenutzte Tool für lokale LLM-Experimente und Entwicklungsumgebungen.

[AI4U Blog](https://ai4u.space/blog/ollama-vs-vllm-2026-local-llm-manager-vs-inference-server)

## Azure AI & Microsoft

Microsoft baut die Foundry-Plattform zur vollständigen Agenteninfrastruktur aus: Work IQ APIs gingen am 16. Juni in GA, Voice Live ist als Echtzeit-Sprach-API generell verfügbar, und Azure OpenAI erweitert sein Realtime-Angebot mit gpt-realtime-1.5 sowie dem Spillover-Feature für stabile Provisioned-Deployments.

### Microsoft Foundry: Work IQ APIs — General Availability
**Produkt:** Microsoft Foundry / Microsoft 365<br>**Datum:** 16.06.2026<br>**Relevanz:** 🔴

Die Work IQ APIs sind nun allgemein verfügbar und geben Entwicklern programmatischen Zugriff auf die M365-Unternehmenskontext-Schicht. Agenten können auf Meetings, Dokumente, Kollaborationsmuster und Workflows zugreifen, ohne eigene Datenpipelines aufzubauen. Ergänzt durch Foundry IQ, das manuelle RAG-Pipelines durch ein SLA-gesichertes Retrieval-Endpoint ersetzt, entsteht eine vollständige Wissensinfrastruktur für Enterprise-Agenten — direkt relevant für Microsoft-Partner-Projekte.

[Microsoft Foundry Blog Build 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-build-2026/) · [InfoQ Foundry Agents](https://www.infoq.com/news/2026/06/microsoft-foundry-agents/)

### Foundry Agent Service: Hosted Agents + Teams/M365-Integration (GA)
**Produkt:** Microsoft Foundry<br>**Datum:** —<br>**Relevanz:** 🔴

Hosted Agents in Foundry Agent Service laufen in isolierten Sandboxes mit dedizierter Compute, Memory und Filesystem-Zugriff; unterstützte Frameworks: Microsoft Agent Framework, GitHub Copilot SDK und LangGraph. Die Teams- und M365-Copilot-Integration ist seit Juni GA — Agenten lassen sich direkt in M365-Tools deployen, mit automatischem Identity-, Permissions- und Policy-Durchsatz. GA für Hosted Agents ist für Anfang Juli 2026 geplant.

[Microsoft Foundry Blog Build 2026](https://devblogs.microsoft.com/foundry/agent-service-build2026/) · [InfoQ Foundry Agents](https://www.infoq.com/news/2026/06/microsoft-foundry-agents/)

### Azure OpenAI: gpt-realtime-1.5 + Spillover GA
**Produkt:** Azure OpenAI Service<br>**Datum:** —<br>**Relevanz:** 🟡

Die neuen Modelle gpt-realtime-1.5 und gpt-audio-1.5 verbessern Instruction Following, Mehrsprachigkeit und Tool-Calling bei Echtzeit-Interaktionen. Das Spillover-Feature ist nun GA und routet Traffic-Spitzen von provisioned Deployments automatisch auf ein Standard-Deployment — stabile SLAs ohne Überprovisioning, praktisch relevant für alle produktiven Azure-OpenAI-Deployments.

[Azure Updates](https://azure.microsoft.com/en-us/updates) · [Microsoft Learn What's New](https://learn.microsoft.com/en-us/azure/foundry-classic/openai/whats-new)

### Foundry Voice Live — General Availability
**Produkt:** Microsoft Foundry<br>**Datum:** —<br>**Relevanz:** 🟡

Voice Live vereint Spracherkennung, Text-to-Speech, Turn Detection, Interrupt-Handling, Avatare und weitere Echtzeit-Konversations-Features in einer einzigen API. Die GA-Version ist der schnellste Einstiegspunkt für Teams, die Voice-Experiences auf Azure aufbauen — besonders relevant für Contact-Center- und Field-Service-Szenarien.

[Microsoft Foundry Blog Build 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-build-2026/)
