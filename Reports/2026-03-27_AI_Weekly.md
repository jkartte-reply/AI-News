## Executive Summary

Die fünf wichtigsten Entwicklungen der Woche — priorisiert nach Relevanz für AI Engineering & Microsoft Partner Kontext:

1. **Microsoft Foundry Agent Service GA + Frontier Suite** — Foundry Agent Service ist jetzt Generally Available mit privaten Netzwerken, Voice Live und MCP-Auth. Dazu Wave 3 von M365 Copilot mit Claude-Integration und die neue E7 Frontier Suite (GA Mai 2026 ab $99/User).
2. **Anthropic Claude Mythos geleakt** — Internes Datenleck enthüllte das nächste Anthropic-Flaggschiff. Capabilities-Sprung vor allem in Coding & Cybersecurity, aktive Cybersecurity-Warnungen im Unternehmen. Hochrelevant für Sicherheitsarchitektur.
3. **OpenAI GPT-5.4 + Mini/Nano** — Am 5. März released, am 17. März folgen Mini/Nano. 1M-Token-Context, 3 Varianten. Stärkste OpenAI-Modelle für Enterprise-Work.
4. **Microsoft Agent Framework RC → GA in Q1** — Vereinigt AutoGen + Semantic Kernel. Für alle Azure-AI-Projekte ab sofort die primäre Framework-Empfehlung. Migration von Semantic Kernel empfohlen.
5. **EU AI Act: August 2026 Compliance-Deadline naht** — Hauptregeln treten am 2. August 2026 in Kraft. KI-Systeme in Kundenprojekten müssen bis dahin auf High-Risk-Einstufung geprüft sein.

## Frameworks & Developer Tools

### Microsoft Agent Framework — Release Candidate (RC 1.0)
**Release:** RC 1.0 vom 19. Februar 2026 | **GA:** Ende Q1 2026 | **Relevanz:** 🔴 Hoch

Das Microsoft Agent Framework (MAF) vereinigt AutoGen und Semantic Kernel zu einem einheitlichen Framework für .NET und Python. Es ist der offizielle Nachfolger beider Frameworks — "Semantic Kernel v2.0", gebaut vom gleichen Team. Die API-Oberfläche ist stabil, alle v1.0-Features sind final.

**Handlungsempfehlung für Microsoft Partner:** Neue Agent-Projekte sollten direkt auf MAF aufsetzen. Bestehende SK/AutoGen-Projekte mit der veröffentlichten [Migrationsdokumentation](https://learn.microsoft.com/en-us/agent-framework/migration-guide/from-semantic-kernel/) umstellen. SK v1.x erhält weiterhin Critical Security Fixes.

[MAF RC Blog](https://devblogs.microsoft.com/semantic-kernel/migrate-your-semantic-kernel-and-autogen-projects-to-microsoft-agent-framework-release-candidate/) | [Learn Docs](https://learn.microsoft.com/en-us/agent-framework/migration-guide/from-semantic-kernel/)

### MCP (Model Context Protocol) v1.27 — Roadmap 2026 veröffentlicht
**Release:** Roadmap März 2026 | **Relevanz:** 🔴 Hoch

MCP hat 97 Millionen monatliche Downloads erreicht, 5.800+ Community- und Enterprise-Server. Die 2026-Roadmap fokussiert auf vier Bereiche:

1. **Transport Scalability** — Stateless Streamable HTTP für horizontales Scaling
2. **Governance Maturation** — Linux Foundation Working Groups, dezentralisierte Leadership
3. **Enterprise Readiness** — Audit Trails, SSO-Auth, Gateway-Behavior, Config Portability
4. **Agent Communication** — MCP als Koordinationsprotokoll für Multi-Agent-Architekturen

Für Consulting-Projekte: Enterprise-Readiness-Features machen MCP jetzt produktionstauglich für größere Deployments.

[MCP 2026 Roadmap](http://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/) | [VentureBeat: MCP Update](https://venturebeat.com/ai/the-open-source-model-context-protocol-was-just-updated-heres-why-its-a-big-deal)
