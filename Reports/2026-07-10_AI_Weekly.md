# AI Weekly Report — 10. Juli 2026

> Recherchiert am 10.07.2026 | Zeitraum: 04.07.–10.07.2026

## Executive Summary

Die Woche vom 4. bis 10. Juli 2026 markiert den Wechsel von angekündigten zu tatsächlich verfügbaren Frontier-Modellen — GPT-5.6 und Grok 4.5 verlassen beide ihre Gating- bzw. Beta-Phase und werden öffentlich nutzbar —, während sich die regulatorische Kluft zwischen EU und China mit je eigenen KI-Sicherheitsmaßnahmen vertieft und OpenAI mit der Atlas-Einstellung seine Produktstrategie weiter auf ChatGPT konzentriert.

- **GPT-5.6 wird öffentlich:** Nach der zweiwöchigen Regierungs-Preview sind Sol, Terra und Luna seit 9. Juli für alle verfügbar — inklusive der neuen Voice-Modelle GPT-Live-1 für natürlichere Gespräche.
- **Grok 4.5 startet public:** xAI veröffentlicht am 8. Juli sein bislang stärkstes Coding-/Agentic-Modell zu aggressivem Preis (2/6 USD pro Mio. Token) und integriert es sofort in Cursor.
- **EU und China regulieren KI-Risiken parallel:** Die EU-Kommission präsentiert am 7. Juli einen Cybersecurity-KI-Aktionsplan, während Chinas neue Regeln für anthropomorphe KI-Interaktion ab 15. Juli ByteDance und Alibaba zwingen, ihre Agenten-Features abzuschalten.
- **OpenAI stellt den Atlas-Browser ein:** Neun Monate nach Launch wandert die Funktionalität zurück in ChatGPT — Teil einer Konsolidierungsstrategie unter CEO Fidji Simo, die parallel Dutzende Legacy-Modelle zum 23. Juli abschaltet.
- **Microsofts Agenten-Stack erreicht Produktionsreife:** Foundry Hosted Agents gehen GA, GitHub Copilot bekommt mit Kimi K2.7 Code sein erstes Open-Weight-Modell — direkt relevant für Partner-Projekte mit Foundry- oder Copilot-Workloads.

## Frameworks & Developer Tools

GitHub Copilot bekommt mit Kimi K2.7 Code sein erstes Open-Weight-Modell im Model-Picker und erreicht mit Copilot Vision volle Bildunterstützung; VS Code 1.128 liefert parallele Multi-Chat-Agentensessions für Claude.

### GitHub Copilot Vision (GA) + Kimi K2.7 Code
**Release:** General Availability<br>**Datum:** 2026-07-01<br>**Relevanz:** 🔴

Copilot Vision (Bild-/PDF-Anhänge im Chat) ist seit 1. Juli GA über VS Code, github.com und Copilot CLI. Am selben Tag zog mit Moonshot AIs Kimi K2.7 Code (1 Billion Parameter MoE, 32 Mrd. aktiv, 256K Kontext, Multi-Head Latent Attention) das erste Open-Weight-Modell in Copilots Model-Picker ein — gehostet von GitHub auf Azure, nutzungsbasiert abgerechnet, Rollout für Pro/Pro+/Max-Pläne.

[GitHub Changelog — Copilot Vision](https://github.blog/changelog/2026-07-01-copilot-vision-is-generally-available/) · [GitHub Changelog — Kimi K2.7](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)

### VS Code 1.128
**Release:** 1.128<br>**Datum:** 2026-07-08<br>**Relevanz:** 🟡

Neue Multi-Chat-Agentensessions erlauben mehrere zusammenhängende Chats parallel (Vergleich von Ansätzen, Branching aus früheren Turns); Subagenten-Transkripte erscheinen als Read-only-Peer-Chats neben der Hauptunterhaltung. Dazu GA für Copilot Vision im Editor sowie OS-weite Keyboard-Shortcuts und konfigurierbare Browser-Tab-Platzierung.

[Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx) · [VS Code Updates](https://code.visualstudio.com/updates/v1_128)

## Azure AI & Microsoft

Microsofts Agenten-Infrastruktur erreicht Produktionsreife — Foundry Hosted Agents gehen GA —, während GitHub Copilot mit einem Open-Weight-Modell und voller Bildunterstützung nachzieht und Microsoft 365 zum 1. Juli seine Copilot-Preisstruktur neu ordnet.

### Foundry Hosted Agents — General Availability
**Produkt:** Microsoft Foundry / Foundry Agent Service<br>**Datum:** 2026-07-08<br>**Relevanz:** 🔴

Hosted Agents in Foundry Agent Service sind ab sofort allgemein verfügbar: Jede Session läuft in einer eigenen Sandbox mit dedizierter Compute-, Memory- und Filesystem-Zugriff, framework-agnostisch für Microsoft Agent Framework, GitHub Copilot SDK, LangGraph und weitere SDKs. Neu unterstützt werden auch Long-Running-Agenten wie OpenClaw mit persistentem State sowie zeitgesteuerte "Routines" (Public Preview). Für Partner-Projekte bedeutet das einen produktionsreifen, Azure-nativen Agent-Runtime statt selbstgehosteter Infrastruktur.

[Microsoft Foundry Blog](https://devblogs.microsoft.com/foundry/hosted-agents-build26/) · [byteiota](https://byteiota.com/foundry-agent-service-ga/)

### GitHub Copilot: Vision GA & erstes Open-Weight-Modell
**Produkt:** GitHub Copilot<br>**Datum:** 2026-07-01<br>**Relevanz:** 🔴

Siehe Frameworks-Sektion: Copilot Vision (Bild-/PDF-Kontext) ist GA, und mit Kimi K2.7 Code steht erstmals ein Open-Weight-Modell im Copilot-Model-Picker — gehostet auf Azure. Für Partner-Teams eröffnet das eine günstigere Modell-Option direkt im bestehenden Copilot-Abo, ohne separaten Anbieter-Vertrag.

[GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)

### Microsoft 365: Copilot als fester Plan-Bestandteil, neue Preise
**Produkt:** Microsoft 365 / Copilot<br>**Datum:** 2026-07-01<br>**Relevanz:** 🟡

Seit 1. Juli bietet Microsoft Business Standard und Business Premium dauerhaft mit eingebautem Copilot an (Standard+Copilot 23,50 USD, Premium+Copilot 32 USD pro Nutzer/Monat); gleichzeitig steigt der Preis für Business Standard ohne Copilot von 12,50 auf 14 USD und die Standalone-Copilot-Lizenz wird teurer. Bestandskunden behalten ihre Preise bis zur nächsten Vertragsverlängerung — Partner sollten Kunden-Lizenzmodelle vor der nächsten Renewal-Runde prüfen.

[Microsoft Licensing News](https://www.microsoft.com/en-us/licensing/news/2026-m365-packaging-pricing-updates) · [Windows Latest](https://www.windowslatest.com/2026/07/05/microsoft-365-just-got-a-price-hike-over-continuous-innovation-but-copilot-is-the-ai-tax-on-businesses/)

## Industry & Research

EU und China ziehen diese Woche mit eigenständigen, aber gegensätzlichen KI-Sicherheitsmaßnahmen nach, während der Kostendruck durch günstigere chinesische Modelle bei US-Unternehmen erstmals messbar Kunden verschiebt.

- **EU Action Plan on Cybersecurity and Artificial Intelligence:** Die EU-Kommission präsentierte am 7. Juli einen Aktionsplan, der KI-Nutzen für Cybersicherheit (Schwachstellenerkennung, Angriffsprävention) und KI-Risiken (automatisierte Angriffe) adressiert: Ein europäischer Blueprint mit ENISA für sicheren Zugang zu fortgeschrittenen KI-Systemen sowie eine sichere Testplattform für kritische Sektoren (Energie, Transport, Gesundheit, Finanzen) sollen bis 2027 operativ sein. [European Commission](https://commission.europa.eu/news-and-media/news/new-eu-plan-address-risks-and-opportunities-advanced-ai-cybersecurity-2026-07-07_en)
- **China: Neue Regeln für anthropomorphe KI-Interaktion treten am 15. Juli in Kraft:** Die im April erlassenen "Interim Measures for the Administration of Anthropomorphic AI Interaction Services" verbieten u. a. emotionale Manipulation und virtuelle Companion-Angebote für Minderjährige; als direkte Folge schalten ByteDances Doubao und Alibabas Qwen ihre KI-Agenten-Erstellungsfunktionen zum Stichtag ab — bestehende Nutzer-Agenten funktionieren danach nicht mehr. [TechNode](https://technode.com/2026/07/06/bytedances-doubao-and-alibabas-qwen-to-shut-down-ai-agent-features-on-july-15/)
- **Chinesische Modelle gewinnen bei US-Unternehmen wegen Kostendrucks an Boden:** Laut CNBC (7. Juli) wechseln zunehmend US-Unternehmen zu offenen chinesischen Modellen, die 60–90% günstiger sind als vergleichbare Angebote von OpenAI und Anthropic — ein Trend, der sich mit dieser Woche parallel öffentlich gewordenen aggressiven Preisen von Grok 4.5 und GPT-5.6 Luna weiter verschärfen dürfte. [CNBC](https://www.cnbc.com/2026/07/07/chinese-ai-models-costs-us-openai-anthropic.html)

## Business News

OpenAI räumt sein Produktportfolio auf — Atlas-Browser-Aus und eine große Modell-Deprecation-Welle —, während Google mit der erneuten Gemini-3.5-Pro-Verschiebung weiter unter Druck steht.

- **OpenAI:** OpenAI stellt den erst im Oktober 2025 gestarteten Atlas-Browser nach neun Monaten ein und verlagert dessen Agentic-Funktionen zurück in ChatGPT (neue Chrome-Extension, erweiterte Desktop-App mit Cloud-Browser). CEO Fidji Simo verfolgt damit eine Konsolidierungsstrategie ("der Browser ist ein Feature, kein Zielprodukt") und lässt parallel Dutzende ältere Modelle in zwei Wellen (23. Juli, 23. Oktober) auslaufen. [Eastern Herald](https://easternherald.com/2026/07/10/openai-atlas-browser-shutdown-chatgpt-strategy/)
- **Google DeepMind:** Google verschiebt Gemini 3.5 Pro erneut — vom ursprünglichen Juni-Fenster nun auf den 17. Juli — und verwirft dabei die bisherige 2.5-Pro-Architektur komplett zugunsten eines Neubaus, der Lücken bei mathematischem Reasoning, SVG-Generierung und Bildqualität schließen soll, um mit GPT-5.6 und Claude Fable 5 mitzuhalten. [BigGo Finance](https://finance.biggo.com/news/6f0c6bb2-795f-4c57-9d09-6db691d7638a)
- **ByteDance / Alibaba:** Doubao (ByteDance) und Qwen (Alibaba) schalten ihre Funktionen zur Erstellung eigener KI-Agenten zum 15. Juli ab, um Chinas neue Regulierung für anthropomorphe KI-Interaktion einzuhalten — ein regulatorisch erzwungener Rückbau von Consumer-Agentic-Features mitten im globalen Agenten-Hype. [TechNode](https://technode.com/2026/07/06/bytedances-doubao-and-alibabas-qwen-to-shut-down-ai-agent-features-on-july-15/)
