## Frameworks & Developer Tools

### Microsoft Agent Framework 1.0 GA
**Release:** v1.0 stable | **Datum:** 03. April 2026 | **Relevanz:** 🔴
Semantic Kernel und AutoGen wurden in einem einzigen, produktionsreifen Open-Source-Framework vereint. Unterstützt 6 Provider (Azure OpenAI, OpenAI, Anthropic, Amazon Bedrock, Google Gemini, Ollama) mit One-Line-Provider-Switch. Highlights: Enterprise Multi-Agent-Orchestration, A2A und MCP Interoperabilität, **DevUI** (Browser-basierter lokaler Debugger für Agent-Traces), Python und .NET. Long-Term Support zugesichert.
[Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/04/06/microsoft-ships-production-ready-agent-framework-1-0-for-net-and-python.aspx)

### MCP (Model Context Protocol) — Governance-Update & 2026 Roadmap
**Release:** Roadmap Update | **Datum:** 08. April 2026 | **Relevanz:** 🔴
Den Delimarsky (Anthropic) wird Lead Maintainer; Clare Liguori stärkt das Design für Production Agent Runtimes. Die 2026-Roadmap adressiert die größten Produktionsprobleme: horizontale Skalierung (Stateless Streamable HTTP, Load Balancer-Support), **Enterprise SSO-Auth**, Audit Trails, Gateway-Behavior und Configuration Portability.
[MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-04-08-maintainer-update/) | [2026 Roadmap](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/)

### GitHub Copilot CLI — General Availability
**Release:** GA | **Datum:** April 2026 | **Relevanz:** 🔴
GitHub Copilot CLI ist jetzt offiziell GA mit Agentic Workflows (Autopilot Mode), **Claude Opus 4.7 Support**, Enterprise Telemetry, Remote MCP Server Config Defaults und **Data Residency für US und EU**. Achtung: Ab 24. April darf GitHub Copilot (Free/Pro/Pro+) User-Interaktionen zum Model-Training nutzen — Opt-Out prüfen!
[InfoQ](https://www.infoq.com/news/2026/04/github-copilot-cli-ga/) | [GitHub Changelog](https://github.blog/changelog/month/04-2026/)

### Microsoft Agent Governance Toolkit
**Release:** Open Source | **Datum:** 03. April 2026 | **Relevanz:** 🟡
Microsoft hat ein Open-Source-Toolkit zur Governance autonomer AI-Agents veröffentlicht. Integration in LangChain Callback Handlers und LlamaIndex TrustedAgentWorker. Adressiert die Governance-Lücke bei Enterprise Agent-Deployments.
[Help Net Security](https://www.helpnetsecurity.com/2026/04/03/microsoft-ai-agent-governance-toolkit/)

## Azure AI & Microsoft

### Azure AI Foundry: Neue MAI-Modelle (Public Preview)
**Produkt:** Azure AI Foundry | **Datum:** April 2026 | **Relevanz:** 🔴

- **MAI-Transcribe-1**: Enterprise Speech Recognition, 3,9% WER auf FLEURS, 25 Sprachen, ~50% günstigere GPU-Kosten als Alternativen, 2,5x schneller als Azure Fast
