## Executive Summary

Die KW 25 markiert die vollständige Produktionsreife des Microsoft-Agenten-Stacks: Work IQ APIs, Foundry Hosted Agents, GitHub Copilot Agent Finder und das Microsoft Agent Framework konvergierten in einer Woche — während SpaceX die Übernahme von Cursor für 60 Milliarden Dollar ankündigte und die US-Regierung erstmals Exportkontrollen für ein spezifisches Frontier-Modell verhängte.

- **Microsoft Agenten-Stack GA:** Work IQ APIs, Foundry Hosted Agents und GitHub Copilot Agent Finder sind produktionsreif — das vollständige Baukastensystem für M365-integrierte Agenten ist jetzt verfügbar.
- **SpaceX übernimmt Cursor für 60 Milliarden Dollar** und konsolidiert damit den KI-Coding-Markt erheblich, während die Unabhängigkeit des wichtigsten Developer Tools in Frage steht.
- **US-Exportkontrolle für Claude Fable 5 und Mythos 5:** Erstmals verhängt die US-Regierung Exportkontrollen für ein spezifisches Frontier-Modell — ein Gouvernanz-Präzedenzfall mit globaler Reichweite.

- **Starke Open-Weight-Woche:** GLM-5.2 (744B MoE, 1M Kontext, MIT-Lizenz) und NVIDIA Nemotron 3 Ultra setzen neue Maßstäbe für frei verfügbare Frontier-Modelle.

## Azure AI & Microsoft

### Work IQ APIs — General Availability
**Produkt:** Microsoft 365 / Azure AI Foundry<br>**Datum:** 2026-06-16<br>**Relevanz:** 🔴

Die Work IQ APIs sind GA und exponieren über 10 generische MCP-Tools sowie eine REST API den gesamten semantischen M365-Index (E-Mail, Kalender, Meetings, Dokumente, LoB-Systeme). Jeder MCP-kompatible Agent (Claude, LangGraph, AutoGen) kann den Work IQ MCP Server direkt ansprechen. Die verbrauchsbasierte Abrechnung über Copilot Credits erfordert klares Cost-Governance-Design — ein direktes Beratungsthema für Microsoft Partner, die M365-integrierte Agenten bauen.

**Produkt:** Azure AI Foundry<br>**Datum:** 2026-06-02<br>**Relevanz:** 🔴
