## Frameworks & Developer Tools

### Microsoft Agent Framework 1.0 GA (Build 2026)
**Release:** 1.0 GA (April 2026) + Build-Erweiterungen (Juni 2026) | **Datum:** 02.–03.06.2026 | **Relevanz:** 🔴

Unified successor zu AutoGen und Semantic Kernel. Bei Build 2026 wurden **Agent Harness** (Shell/Filesystem-Zugang, Human-in-the-Loop, Context Management), **Hosted Agents in Foundry Agent Service** (containerisiertes Deployment, Autoscaling, Managed Session State, Observability) und **Framework-agnostische Observability** (LangGraph, CrewAI, etc.) vorgestellt. Python und .NET werden beide unterstützt.

[Microsoft Agent Framework Build Blog](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026/)
[Hosted Agents Foundry](https://devblogs.microsoft.com/foundry/agent-service-build2026/)

### MCP Specification Release Candidate (Mai/Juni 2026)
**Release:** RC veröffentlicht | **Datum:** Finales Spec: 28.07.2026 | **Relevanz:** 🔴

Kern-Änderungen des RC: **Stateless Protocol** (6 SEPs kooperieren, MCP entfernt Session-State aus dem Protokoll), **MCP Apps** (Server liefern interaktive HTML-UIs für Hosts in sandboxed iframes), **Tasks Extension** (asynchrone Aufgaben mit `tasks/get`, `tasks/update`, `tasks/cancel`), **Authorization Hardening**, **Deprecation Policy**. MCP hat nun über 200 Server-Implementierungen. Tier-1-SDKs müssen innerhalb von 10 Wochen Support liefern.

[MCP RC Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)
[MCP Roadmap](https://modelcontextprotocol.io/development/roadmap)

### Microsoft Build 2026 — Gesamtüberblick
**Produkt:** Microsoft Foundry / Azure AI | **Datum:** 02.–03.06.2026 | **Relevanz:** 🔴

Build 2026 war vollständig auf agentic AI ausgerichtet. Die wichtigsten Partner-relevanten Ankündigungen:

- **Microsoft Foundry IQ (GA):** Unified Knowledge Layer aus Work IQ, Fabric IQ, Azure SQL, File Search und MCP hinter einem SLA-gesicherten Retrieval-Endpunkt. Verfügbar in GitHub Copilot, Foundry und Copilot Studio.

- **Memory in Foundry (Public Preview):** Procedural, User und Session Memory für langlebige Agenten.

- **Agent 365 SDK (GA):** Deployment von Agenten direkt in Teams und Microsoft 365 Copilot.
- **Microsoft Scout:** Neuer persönlicher Arbeitsagent, der proaktiv Meeting-Prep, Scheduling und Routineaufgaben in Teams/Outlook übernimmt.
- **Web IQ:** Echtzeit-Grounding für Agenten; 2,5× schneller als nächste Alternative laut Microsoft.
- **Fireworks AI on Microsoft Foundry (GA):** Open-Model-Inferenz über single Azure Endpoint mit Enterprise SLAs.
